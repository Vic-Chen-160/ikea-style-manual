Parts bag: what's in the skill

Lettered callouts work for any structure: folders, anatomy, a screen layout.

ARules: page catalog, visual rules, writing rules, SVG gotchas.
BDesign system: CSS, every component, the drawing kit. Always the starting point.
CSelf-check: renders desktop + mobile screenshots for the agent to inspect.
DOutput: one self-contained HTML file. Works offline, prints as a booklet.
Pages6–15, one question per page
Words per step≤ 3 sentences
Line weight2.4 everywhere, 3.4 for the recommended outcome
ColorBlack on white. One tiny accent, at most.

Never do

The four ways a manual stops being a manual.

✕

Paragraphs

✕

✕

Colorful

Black line art on white. That's the whole look.

✕

Unchecked SVG text

SVG text never wraps. Always screenshot.
